# チャンピオン顔画像・ラベル

- 取得日: 2026-09-18
- Riot公式Data Dragon: バージョン16.18.1、言語ja_JP / en_US、全173体。
- [公式配布仕様](https://developer.riotgames.com/docs/lol#data-dragon)
- [バージョン一覧](https://ddragon.leagueoflegends.com/api/versions.json)
- [日本語一覧](https://ddragon.leagueoflegends.com/cdn/16.18.1/data/ja_JP/champion.json)
- [英語一覧](https://ddragon.leagueoflegends.com/cdn/16.18.1/data/en_US/champion.json)

各PNGは公式の128×128チャンピオンアイコンを無加工で保存しています。個別取得URLとSHA-256、日本語名・英語名・IDはcatalog.jsonに収録。原典一覧の全IDと保存画像を照合しています。画像・キャラクターの権利はRiot Games等の権利者に帰属します。本ツールはRiot Gamesによる公式製品ではありません。

画像素材の取得と、試合情報の取得は別です。実行時に外部APIへ接続せず、試合情報は手動入力・ゲーム元画面のローカルOCRを使用します。
