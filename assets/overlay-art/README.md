# 配信デモ用の画像素材

1. 1920×1080 pxのキャンバスで制作し、下のファイル名でPNGを書き出します。透過が必要な箇所はアルファチャンネルを使ってください。
2. PNGをこのフォルダに置き、プロジェクト直下の `demo.bat` を開きます。
3. デモの「素材の差し替え」で「素材を読み直す」を押してから、対象のシーンを選びます。チーム名、選手名、チャンピオン画像、数値はアプリが上に重ねます。文字が入る場所は、素材を入れる前のデモで確認できます。

| ファイル名 | シーン | 制作範囲（初期設定、左上が原点） |
|---|---|---|
| `draft.png` | BAN / PICK | 左右各386 px・上200 px・下228 px。中央のカメラ領域は透過表示されます。 |
| `game.png` | 試合中 | 上部スコア欄。左端はX=390 px、幅は1140 pxです。スコア欄の範囲に切り抜いて表示します。 |
| `result.png` | 試合結果 | 全面。勝利チーム・両チームの成績表・ダメージ比較を重ねます。 |
| `cover.png` | 中断 | 全面。中央に中断の見出し・補足・チームロゴを重ねます。 |

1シーンずつ試せます。画像を外して「素材を読み直す」と、そのシーンは標準デザインに戻ります。配置を調整している場合は、デモで使用している配置に合わせてください。素材の試着はデモ上映ページで行います。
